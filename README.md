# mono.dev Portfolio

A modern, highly interactive, and responsive developer portfolio website.

## Features
- Bilingual Support: Seamless switching between English and Korean using React Context.
- Responsive Design: Fully optimized layout for PC, tablet, and mobile devices.
- Modern UI: Clean, academic-yet-modern tech lab aesthetic using Tailwind CSS.
- Sections: Includes Home, About, Projects, and Contact with a functional email form.

## Tech Stack
- Frontend: React, Vite
- Styling: Tailwind CSS v4, CSS Variables
- Animation: Framer Motion
- Deployment: Vercel

## Running Locally
1. Clone the repository: `git clone https://github.com/monolail/portfolio-site.git`
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`

# mono.dev 포트폴리오

현대적이고 반응성이 뛰어난 프론트엔드 개발자 포트폴리오 웹사이트입니다.

## 주요 기능
- 다국어 지원: React Context를 활용하여 한국어와 영어를 원활하게 전환합니다.
- 반응형 디자인: PC, 태블릿, 모바일 기기에 완벽하게 최적화된 레이아웃을 제공합니다.
- 모던 UI: Tailwind CSS를 활용하여 깔끔하고 전문적인 느낌의 디자인을 구현했습니다.
- 페이지 구성: 홈, 소개, 프로젝트, 이메일 연동이 가능한 연락처 섹션으로 구성되어 있습니다.

## 기술 스택
- 프론트엔드: React, Vite
- 스타일링: Tailwind CSS v4, CSS 변수
- 애니메이션: Framer Motion
- 배포: Vercel

## 로컬 실행 방법
1. 저장소 클론: `git clone https://github.com/monolail/portfolio-site.git`
2. 패키지 설치: `npm install`
3. 로컬 서버 실행: `npm run dev`
